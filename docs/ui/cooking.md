# UI: cooking history and ratings

Follows `conventions.md`.

## "I cooked this" sheet
```
+------------------------------------+
| Cooked it                          |
| Date    [ today ]                  |
| [x] Tested (a real attempt)        |
| Rating  [ * * * * - ]  (optional)  |
| Note    [ ...................... ] |
|           [ Cancel ]   [ Save ]    |
+------------------------------------+
```

## Recipe page
History list: date, member name, rating, note; own entries can be edited or deleted. Header shows household average, number of ratings and last cooked. Unrated is shown as "not rated", never as zero.

## Recipe list filters
Tested or not, rating range, total time range, and a member selector for whose ratings to use.
