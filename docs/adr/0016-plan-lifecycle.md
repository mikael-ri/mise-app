# ADR-016 — Plan lifecycle, calendar and leftovers

**Status:** Accepted · **Cards/milestone:** Milestone C · **Baseline:** tech §16 (frozen)

## Decision
Plans: draft, approved, archived. Slots: proposed, approved, cooked, skipped. Weeks default to ISO (Monday start) but any seven-day window is allowed. Household timezone Europe/Helsinki with local dates. Leftovers link at component level (`meal_components.leftover_source_component_id`). Changing an approved slot marks any linked shopping import stale.
