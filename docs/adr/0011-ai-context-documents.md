# ADR-011 — AI context: version-controlled prompts only

**Status:** Accepted · **Cards/milestone:** B, D · **Baseline:** tech §16 (frozen)

## Decision
P0 AI context is version-controlled prompt files plus a short hand-written house-rules file. No document upload UI, file search or vector store in P0. Any later uploaded document is untrusted data.

## Read more
Spec §6; tech §9.2

Spike results and amendments go in an *Addendum* section below, never by editing the frozen documents.
